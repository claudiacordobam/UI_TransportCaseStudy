# UI Transport Case Study
## 📌 Overview

This project is a UI case study for a mobile application focused on improving the public transport experience. The goal was to design a user-centred solution based on research, usability principles and accessibility considerations.

---

## ❗ Problem

Public transport systems can often be confusing and inefficient for users, especially when it comes to finding routes, understanding schedules and navigating different options. This project aims to improve clarity and usability through a digital solution.

---

## 👩‍💻 My Role

- User research and interviews  
- Analysis of user needs and pain points  
- UI design (user flows and information architecture)  
- Wireframing and prototyping  

---

## 🔎 Design Process

### 1. Research
I conducted user interviews and analysed common pain points when using public transport systems.

### 2. Definition
I defined user needs and structured the core functionalities of the app.

### 3. Design
I created user flows, information architecture and wireframes to structure the experience.

### 4. Prototyping
An interactive prototype was developed to visualise and refine the user experience.

## 🎯 Key Focus Areas

- Usability and clarity  
- Accessibility  
- User-centred design  
- Simplified navigation  

---

## 🚀 Outcome

A conceptual mobile application designed to improve the experience of navigating public transport systems through a clear and user-friendly interface.
